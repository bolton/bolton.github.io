Theming

      
Make it match your site

      
The badges on this page use CSS custom properties to pick up the site's colors and fonts. Here's a lighter take for Mount Rainier.

      

        Washington campfire restrictions
        
wa-campfire-status {
  --wcs-bg: #f4efe4;
  --wcs-fg: #1d2420;
  --wcs-muted: #6b6a5f;
  --wcs-border: #ddd3bf;
  --wcs-radius: 4px;
  --wcs-font: Fraunces, serif;
  --wcs-none: #3f7d4e;
  --wcs-restricted: #b5651d;
  --wcs-banned: #a83a2a;
}

      

    

  


  

    

      
Terms

      
One condition

      

        
The badge is free to use on any site, as long as the credit link to Washington campfire restrictions stays visible next to it. Without the link, the badge shows no status.

        
The data comes from agency notices and can be late or wrong. The agency's own notice is what counts. Read the full terms on beexploring.com.
