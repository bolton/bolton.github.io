NWS Forecast Widget

A National Weather Service forecast for any US latitude and longitude. One script tag, no API key, no build step, no framework. Data comes straight from api.weather.gov.

Theming

      
Make it match your site

      
Every widget on this page uses CSS custom properties to pick up the site's colors and fonts. Here's a lighter take for Snoqualmie Pass.

      

        
        
nws-forecast {
  --nws-bg: #f4efe4;
  --nws-fg: #1d2420;
  --nws-muted: #6b6a5f;
  --nws-accent: #b5651d;
  --nws-border: #ddd3bf;
  --nws-radius: 4px;
  --nws-font: Fraunces, serif;
}

      

    

  


  

    

      
Iframe embed

      
No script tag needed

      
The hosted embed page takes the same options as URL parameters, plus heading and theme=light|dark|auto.
